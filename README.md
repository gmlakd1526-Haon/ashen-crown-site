## 고치는 방법
문구는 `tools/page.template.html` 한 파일에 한국어(`lang="ko"`)·영어(`lang="en"`)가 함께 들어 있습니다.
고친 뒤 `python3 tools/build.py`를 실행하면 `index.html`(한국어)과 `en/index.html`(영어)이 만들어집니다.
